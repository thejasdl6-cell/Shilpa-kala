# Shilpa-kala
Shilpa-Kala is an Android-based mobile application developed to support local artisans and handicraft makers in promoting their handmade products digitally.
## Features
-Artisan Information Management
-Allows users to enter artisan details
-Stores artisan name temporarily during runtime
-Automatically generates professional branding text
-Displays artisan and product details in formatted style
-Instantly displays generated branding information
-Dynamic TextView updates
## Tech stack
XML, Material Design, Technology, Java, Android SDK, Android Studio, Gradle, Android OS
